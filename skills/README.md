# Skill domains

VoxStudio Pro skills are grouped by production domain:

- `video-editing/` — timeline editing, captions, color, motion graphics, and video generation workflows.
- `recording/` — capture and recording workflows.
- `transcription/` — speech-to-text and transcript workflows.
- `dubbing/` — translation, voice generation, and dubbing workflows.

Each skill lives at `skills/<domain>/<skill-id>/SKILL.md`. Skill IDs must be globally unique across all domains.
